# An App Built for my Family
Built using PostgreSQL, Express.js, React, and Node.js (PERN), this app was built to help with some tedious processes at home. Initially, this will just include weekly meal planning, but other functions may become available based on their potential needs or suggestions.

# Can I use it?
Sure! You'll have to set things like PostgreSQL up yourself, but other than that you're free to use this app for your own uses. 

# Why PostgreSQL?
I previously followed a tutorial to learn the MERN stack, which utilizes MongoDB instead of PostgreSQL. While effective, MongoDB has limited functionality for relations between 2 tables, which is something I need for this app. While I know there are workarounds for MongoDB, I decided to settle for something I was more familiar with, hence PostgreSQL.

For this, I loosely followed [freeCodeCamp's guide on the PERN stack](https://www.youtube.com/watch?v=ldYcgPKEZC8) to get an idea of how to use node-postgres (the pg package). Other than that, I heavily referenced what I learned from learning the MERN stack to get everything else running.
